# kdurgareddy.github.io

Personal portfolio of **Durga Reddy Kovvuri**, a software developer working on cloud-native systems and Generative AI applications.

Live at **https://kdurgareddy.github.io**

A single self-contained `index.html` (HTML, CSS and vanilla JavaScript, no build step), with dark and light themes, an animated network background, typed role, scroll reveals, interactive project cards and a contact form.
